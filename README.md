# Regnum 

## Integrantes del Grupo
* Felipe Petronacci

## Descripción del Juego
Regnum es un videojuego de rol táctico, acción y mazmorras de tipo Roguelike 2D con perspectiva cenital (top-down) y una estética puramente retro basada en texto plano (ASCII). Ambientado en un universo donde la humanidad se revela contra deidades mitológicas tiránicas usando armas de fuego, el sistema combina la generación procedimental de mapas por habitaciones con mecánicas de combate Bullet Hell en tiempo real.

## Tecnologías Utilizadas
* **Framework Principal:** LibGDX (Versión 1.12.x)
* **Lenguaje de Programación:** Java 21
* **Gestor de Proyectos y Dependencias:** Gradle
* **Diseño de Niveles:** Tiled Map Editor (Formatos de mapas .tmx)
* **Plataforma Objetivo:** Escritorio (Desktop - Windows, macOS y Linux)
# Cómo Compilar y Ejecutar el proyecto

## Pasos:

## 1. Clonar el repositorio:

``` 
git clone https://github.com/FelipePetronacci/regnum-proyecto-final
```
```
cd proyecto-final-tp
```

## 2. Compilar el proyecto con el wrapper de Gradle incluido en LibGDX:

### Windows:
``` 
gradlew.bat build
```

### Linux / macOS:
``` 
./gradlew build
```


## 3. Ejecutar el juego en escritorio:

### Windows:
``` 
gradlew.bat lwjgl3:run
```

### Linux / macOS:
``` 
./gradlew lwjgl3:run
```
